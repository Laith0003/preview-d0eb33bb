PP Editorial New (Pangram Pangram) is the intended display typeface.

Drop the licensed web files here, named:
  PPEditorialNew-Ultralight.woff2
  PPEditorialNew-Regular.woff2
  PPEditorialNew-Italic.woff2

The @font-face rules in src/index.css already point to these paths. Until the
files are present, the site renders with Instrument Serif (loaded from Google
Fonts), the closest free analog, so the layout and rhythm are accurate now and
upgrade automatically once the licensed font is added.
